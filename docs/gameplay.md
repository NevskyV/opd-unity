# Физика
Гравитация в глобальных настройках установлена (0, -9.81, 0), но игнорируется игроком, на прыжок у него гравитация (0, 5, 0), на падение (0, 20, 0).
На игроке есть Rigidbody 2D и Capsule Collider 2D. Уровень сделан из тайл мапы и использует Tile Collider 2D.

# Префабы
В проекте используются 4 префаба: 
1. Игрок.  Скрипт Player Character позволяет перемещать персонажа. Скрипт Player Anim позволяет анимировать его движения. Скрипт Player Anim позволяет анимировать его движения. Скрипт Player Hold Item позволяет игроку брать, использовать и бросать предметы.
2. Декоративная трава
3. Рычаг, который позволяет что-то активировать. Скрипт Lever содержит эту логику.
4. Декоративный задний фон для параллакса

# Inspector
В Player Controls можно поменять управление. В Player Character можно изменить максимальное здоровье, физику перемещения и прыжка, отключить приседание, изменить логику при падении за карту.
