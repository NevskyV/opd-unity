#Build_settings
В Build Settings (Build Profiles) можно выбрать разные плафтормы, но в нашем случае только Windows. Также в настройке плафтормы можно выбрать на архитектруе чего собирается проект.

#Package_Manager
Через Package Manager установлены модули 2D анимаций, спрайтов, безошибочного подключения всех этих модулей, а также модули подключения Visual Studio, контроля версия Unity и модуль Burst

#Структура папок
Есть одная общая папка Assets внутри которой есть две папки: IndieMarc и Settings. В папке Settings есть тольког папка Scenes. В папке IndieMarc находятся следующие папки: Scenes и PlatformerDemo, где папка  PlatformerDemo хранит в себе папки Editor, Materials, Prefabs, Scripts, Sprite, TitleMap, где соответсвенно лежат спрайты окружения, фона.

Приблизительный размер проекта 2,16 Гб
